# Tutor Curriculum Builder

Скилл для Claude + компаньон-приложение, которые вместе закрывают весь
цикл репетитора: **программа → ведение занятий в Perplexity → трекинг
прогресса**. Три части системы:

1. **Программа** (JSON + Markdown, по запросу — Word) — загружается в
   Perplexity Project как файл (Files).
2. **Instructions** (системный промпт) — вставляется в поле Instructions
   Perplexity Project. Описывает, как ИИ-репетитор ведёт занятия: этапы
   ИЗУЧЕНИЕ → ТЕСТ → РАЗБОР, команды («дальше», «тест»), контрольные
   срезы, пробелы из предыдущего уровня — и генерирует по ходу занятий
   строки отчётов (`ОТЧЁТ ТЕСТА` / `ОТЧЁТ ТЕМЫ`).
3. **«Дневник репетитора»** (`apps/tutor-diary.html`) — офлайн
   веб-приложение (один HTML-файл, данные в localStorage, без сервера и
   без интернета) для любого предмета и любого числа детей, с явным
   переключателем профиля ребёнка. Репетитор копирует строки
   ОТЧЁТ ТЕСТА/ОТЧЁТ ТЕМЫ из Perplexity и вставляет их сюда — получает
   статистику по предметам и журнал ошибок по темам.

Скилл (пункты 1–2) собирает вводные о ученике и цели, строит план по
модулям и темам (тема → цель → содержание → домашнее задание → способ
проверки) и пишет Instructions под конкретного ученика. Приложение
(пункт 3) — универсальное и не требует настройки под предмет.

## Как использовать

### В Claude.ai / Claude Desktop / Claude Code
1. Скачайте папку `tutor-curriculum-builder/` (ту, что с `SKILL.md` внутри).
2. Добавьте её в настройки как пользовательский скилл (Settings → Capabilities → Skills,
   либо поместите в `/mnt/skills/user/` — зависит от интерфейса).
3. В чате опишите ученика и цель, например:

   > Составь программу занятий по математике для 9 класса, готовимся к ОГЭ,
   > занятия по 60 минут 2 раза в неделю, до конца апреля. Слабое место —
   > геометрия.

   Claude соберёт недостающие вводные (если нужно) и построит и программу,
   и текст Instructions.

### Дальше — в Perplexity
1. Создайте новый **Project** в Perplexity.
2. В поле **Instructions** вставьте содержимое файла
   `instructions/<...>-instructions.md`.
3. В **Files** загрузите файл программы `programs/<...>.md` (или
   `.json`) **и сам файл учебника** (PDF/DOCX), если ученик занимается
   по конкретному учебнику. Это обязательный шаг — без реального файла
   учебника Perplexity не сможет свериться с текстом и рискует
   придумывать номера упражнений и содержание параграфов.
4. Откройте чат внутри проекта — Perplexity начнёт вести занятия по
   программе, следуя вставленным Instructions.
5. Рекомендуется дополнительно включить режим **«Учитесь шаг за шагом»**
   (Learn step by step, доступен через «+» в строке ввода) — по опыту
   он усиливает пошаговое объяснение материала.

### Трекинг прогресса — «Дневник репетитора»
1. Откройте `apps/tutor-diary.html` прямо в браузере (двойной клик по
   файлу — интернет не нужен).
2. Если это первый раз — создайте профиль ребёнка кнопкой
   «+ Добавить ребёнка» в шапке страницы. Пока профиль не выбран, форма
   добавления записи скрыта. Все записи автоматически привязываются к
   выбранному профилю — отдельного поля «Ребёнок» в форме больше нет;
   переключаться между детьми можно в любой момент тем же селектором.
3. По ходу занятий Perplexity будет выводить строки вида
   `ОТЧЁТ ТЕСТА: ...` и `ОТЧЁТ ТЕМЫ: ...` — скопируйте такую строку и
   вставьте в поле «Добавление записи» дневника (выбрав соответствующий
   режим — «Тест» или «Тема»), нажмите «Разобрать строку», затем
   «Сохранить запись». Если распознанный предмет похож на уже
   встречавшийся, но не совпадает точь-в-точь (например, «английский» и
   «английский язык»), дневник предупредит об этом под полем «Предмет»,
   чтобы статистика не расползалась по дублирующим названиям.
4. Дневник сам посчитает статистику по каждому предмету и покажет журнал
   ошибок по темам — работает для любого числа предметов и детей, каждый
   ребёнок видит свои записи через переключатель профиля.

### Формат вывода
- `programs/<предмет-ученик>.json` — структурированные данные (машиночитаемые).
- `programs/<предмет-ученик>.md` — та же программа в читаемом виде, для Files.
- `instructions/<предмет-ученик>-instructions.md` — системный промпт для
  поля Instructions.
- `.docx` — по запросу («сделай в Word»), только для программы, оформляется
  как аккуратный документ с таблицей занятий.

Примеры — в [`examples/programs/`](examples/programs/) и
[`examples/instructions/`](examples/instructions/). Все примеры
гипотетические: вымышленные ученики, вымышленные или условные учебники,
придуманные номера страниц/упражнений — они показывают только формат, а
не проверенное содержание реального издания. Один из примеров
(`geometria-8-gap-year-*`) отдельно демонстрирует случай пропущенного
учебного года — как вопрос о пропущенных темах прошлых классов (раздел 2
скилла) превращается во вводный модуль повторения перед основной
программой.

## Как это устроено

Логика и структура — в [`tutor-curriculum-builder/SKILL.md`](tutor-curriculum-builder/SKILL.md).
Там описаны:
- какие вводные собираются перед составлением программы (предмет, уровень
  ученика, пропущенные темы прошлых классов, цель, дедлайн, формат
  занятий, кто будет заниматься с ИИ);
- JSON-схема программы;
- принципы методиста (измеримые цели, контрольные срезы каждые 7–8 тем,
  конкретные ДЗ и способы проверки);
- шаблон Instructions для Perplexity Project (роль, как объяснять, как
  проверять, тон общения, отслеживание прогресса, ограничения).

## Как адаптировать под себя

Скилл — это обычный текстовый файл, редактируйте `SKILL.md` под свои нужды:
- изменить частоту занятий-повторений;
- добавить поля в JSON-схему (например, «учебник/ресурсы», «уровень
  сложности», «стоимость занятия»);
- сменить язык программы;
- задать свой фирменный стиль репетитора/школы.

## Альтернатива без Claude Code — портативные промпты

Оба скилла (`tutor-curriculum-builder` и `textbook-prep`) рассчитаны на
Claude Code — механизм автозагрузки скиллов и, для `textbook-prep`,
инструмент постраничного чтения PDF там специфичны именно для него. Если
нужно получить тот же результат в другом инструменте (ChatGPT, Gemini,
локальная модель через Ollama и т. п.), в [`alt-prompts/`](alt-prompts/)
лежат две портативные версии — обычный текст промпта без Claude
Code-специфики, который можно вставить первым сообщением в любой чат:

- [`alt-prompts/curriculum-builder-prompt.md`](alt-prompts/curriculum-builder-prompt.md)
  — интервью + сборка программы и Instructions. Задача чисто текстовая, без
  чтения файлов моделью, поэтому качество должно быть сопоставимым почти в
  любой модели, включая локальные.
- [`alt-prompts/textbook-prep-prompt.md`](alt-prompts/textbook-prep-prompt.md)
  — чистка и разметка учебника. Здесь риск выше: без готового инструмента
  постраничного чтения PDF результат сильно зависит от того, насколько
  хорошо конкретная модель читает прикреплённые файлы и распознаёт
  математическую нотацию на сканах. Для локальных моделей через Ollama это
  реалистично на чистом текстовом PDF, но на сканах точность стоит
  перепроверять тщательнее, чем предполагает шаг обязательной сверки внутри
  промпта — используется на свой страх и риск.

Оба промпта держатся вручную в синхроне с соответствующими `SKILL.md` —
при правке скилла проверяйте, не разошлась ли портативная версия
(напоминания об этом продублированы в шапках самих файлов). Вторая пара
дублей — копии дневника `apps/tutor-diary.html` и
`tutor-curriculum-builder/assets/tutor-diary.html`: они должны быть
побайтово одинаковы. Быстрая проверка после правок дневника:

```
fc /b apps\tutor-diary.html tutor-curriculum-builder\assets\tutor-diary.html
```

(в Git Bash — `cmp apps/tutor-diary.html tutor-curriculum-builder/assets/tutor-diary.html`;
нет вывода — значит, файлы совпадают).

## Архитектура: что зафиксировано и почему

Это финальная структура на текущий момент. Ниже — не только что выбрано,
но и что рассматривалось и было отклонено, чтобы не пересматривать это
заново без новых вводных.

- **ИИ-репетитор — Perplexity, альтернативы не подошли.** Gemini Gems
  (бесплатный) проверялся на практике — не держит длинную системную
  инструкцию, здоровается заново в каждом сообщении, галлюцинирует.
  Yandex Алиса AI — бесплатна, но не подтверждено, что держит
  зафиксированную инструкцию через много сообщений подряд, а бесплатных
  запросов к Pro-модели всего 5 в день, дальше — тихий откат на слабую
  Lite. Yandex AI Studio по форме точный аналог Perplexity Project
  (инструкции + база знаний), но это платный pay-per-token сервис Yandex
  Cloud без устойчивого бесплатного тарифа. ChatGPT Projects не
  тестировали — остаётся резервным вариантом (бесплатно, 5 файлов на
  проект).
- **Дневник репетитора — автономный HTML-файл с `localStorage`, без
  бэкенда.** Изначально рассматривался как артефакт, генерируемый прямо
  в Perplexity — это сняло бы вопрос офлайна и синхронизации между
  устройствами. Проверено на практике: генерация приложений в Perplexity
  (Labs) доступна только на платных тарифах (Pro и выше) и Perplexity
  прямо подтвердил, что данные формы не сохраняются в аккаунте и не
  синхронизируются между устройствами. Полноценный облачный бэкенд
  (Supabase/Firebase/Yandex Cloud) избыточен для масштаба задачи (один
  репетитор, двое детей) — требует авторизации и правил доступа. Если
  станет тесно без синхронизации между устройствами, соразмерный
  следующий шаг — Google Apps Script + Google Таблица как лёгкий
  бесплатный бэкенд, либо (если все устройства на Chrome/Edge) хранение
  данных в JSON-файле внутри уже синхронизируемой папки Яндекс.Диска
  через File System Access API. Ни один из вариантов не реализован — это
  задел на будущее, не текущая архитектура.
- **Генерация Instructions/программы — пока целиком через модель.**
  Интервью и авторство содержания программы (темы, номера упражнений,
  формулировки целей) требуют суждения модели. Но превращение готового
  `program.json` в `program.md`/`instructions.md` — механическая
  подстановка по шаблону (раздел 5 SKILL.md) и может быть вынесена в
  отдельный Python-скрипт без единого обращения к модели — устранило бы
  рассинхрон чисел между документами и убрало бы зависимость от
  `/mnt/skills`-путей вне claude.ai. Не реализовано.
